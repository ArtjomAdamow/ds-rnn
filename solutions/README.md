# Solutions

Reference solutions for the exercises in this repository. Open one alongside its source notebook to check your work.

| File                                                       | Description                                                                                       |
| ---------------------------------------------------------- | --------------------------------------------------------------------------------------------------- |
| [**Recurrent Neural Networks**](1_rnn_intro.ipynb)         | Bidirectional LSTM comparison, a hidden size and depth sweep, and forecast error against window length. |
| [**Transformers and Attention**](2_transformer_intro.ipynb) | Attention weights of a trained model, a hyperparameter sweep, IMDB text classification, and a decoder layer with look-ahead masking. |

> [!NOTE]
> The solution notebooks keep the lesson code the exercises build on, so each one runs end to end on its own. The IMDB solution downloads the dataset through Keras on first run.
